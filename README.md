# 李新玲 · 个人作品集网站 使用说明

## 怎么修改内容（不用懂代码）

所有文字、数据、图片路径都集中在 **`js/data.js`** 一个文件里，用任意文本编辑器（记事本、VS Code 都行）打开，改引号里的中文即可：

- **改文字**：直接替换引号里的内容。
- **换图片**：把新图片放进 `assets/` 文件夹，然后把 `src: "assets/xxx.png"` 改成你的新文件名。
- **图片留空待补充**：把 `src: ""` 保留，页面会显示粉色虚线"待补充"占位框，之后随时填上。
- **加图片位置**：在某个项目的 `images` 数组里加一行 `{ src: "", caption: "说明文字" }`。
- **加项目 / 加技能 / 改联系方式**：照着现有格式复制一段再改即可。

改完保存，刷新浏览器就能看到效果。
